Шаг 4 — обязательное добавление и подтверждение домена

Это главный блокирующий шаг.
Пока он не пройден — в продукт нельзя.

Цель шага

Подтвердить, что пользователь реально владеет доменом компании и будет работать от него.

Что видит пользователь

Заголовок:
Verify your domain

Подзаголовок:
You need a verified domain to continue

Что показываем на экране

Если на прошлом шаге был введён сайт, то домен уже подставлен автоматически.

Например:

Website: company.ee
Domain to verify: company.ee

Если домен не удалось корректно вытащить — даём поле:

Domain

и кнопку:

Use this domain
Что пользователь должен сделать
1. Подтвердить сам домен через DNS

Ты даёшь пользователю одну verification TXT запись.

Поля в таблице:

Type: TXT
Host / Name
Value
TTL

Рядом кнопки:

Copy
Check DNS
Логика шага
Пока домен не verified:

Пользователь не может открыть:

Search
Companies
Contacts
Lists
Campaigns
Inbox
Analytics

То есть всё ядро продукта заблокировано.

Что можно:
находиться в onboarding
менять домен
повторно проверять DNS
читать подсказки
Статусы на этом шаге
1. not_started

Домен ещё не добавлен

2. pending_verification

Запись показана, ждём DNS

3. checking

Система сейчас перепроверяет DNS

4. verified

Домен подтверждён

5. failed

Запись не найдена или введено неверно

Что должно быть в интерфейсе
Блок 1 — Domain
Domain: company.ee
Status badge: Pending / Verified / Failed
Блок 2 — DNS record

Простая таблица:

Type
Host
Value
Блок 3 — Help

Очень коротко:

add this DNS record at your domain provider
wait a few minutes
click Check DNS

Без длинных текстов.

Кнопки

Основная:

Check DNS

Дополнительные:

Edit domain
Copy value

Если verified:

Continue
Важная логика backend

После нажатия Check DNS:

система проверяет наличие TXT записи
если запись совпала → домен получает статус verified
workspace status меняется на следующий этап

Например:
sender_setup_required

Если пользователь хочет “пропустить”

Пропустить нельзя.

Можно только:

выйти
вернуться позже

Но в продукт он не входит, пока домен не verified.

Что делать, если домен не подтверждается

Показывать короткие статусы:

Record not found
Wrong value
DNS still propagating

И кнопку:

Check again
Очень важный UX-момент

На этом шаге не надо пока грузить человека SPF/DKIM/DMARC.

Сначала только одно:
подтверждение владения доменом

Это уменьшает хаос.
